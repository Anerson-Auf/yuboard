# Push-уведомления Flowboard

Flowboard использует стандартный Web Push. Нативное приложение, Apple Developer Program и сертификат разработчика не нужны. Для iPhone требуется iOS/iPadOS 16.4+ и запуск Flowboard как приложения с экрана «Домой».

## Один раз на сервере

В каталоге проекта сгенерируйте пару VAPID-ключей:

```bash
node scripts/generate-vapid-keys.mjs
```

Вставьте обе напечатанные строки в `.env` и укажите контакт администратора:

```dotenv
FLOWBOARD_WEB_PUSH_VAPID_PUBLIC_KEY=...
FLOWBOARD_WEB_PUSH_VAPID_PRIVATE_KEY=...
FLOWBOARD_WEB_PUSH_VAPID_SUBJECT=mailto:admin@example.com
```

Приватный ключ не передаётся браузерам, не добавляется в Git и не должен меняться после запуска. Затем выполните обычный деплой:

```bash
./deploy/flowboard-pm2.sh deploy
```

## Для пользователя iPhone

1. Открыть Flowboard в Safari.
2. Нажать «Поделиться» → «На экран Домой».
3. Открыть сайт именно через новую иконку Flowboard.
4. Открыть «Уведомления» и нажать «Включить push-уведомления».

Подписка создаётся для конкретного аккаунта и устройства. Она получает все обычные уведомления Flowboard: упоминания, ответы, назначения, ожидание действия, проверки, подписку на карточку и будущие события, создающие запись в `card_notifications`.
